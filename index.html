Get the application

Download Villa Martis POS for Windows

Installation guide

  1. Open the download page and download the Villa Martis Hotel POS setup file.
  2. When the download is complete, locate POS Desktop Setup 1.0.0.exe in your Downloads folder.
  3. Double-click the file to start the installer.
  4. Follow the installation prompts, then open Villa Martis POS from the Start menu or desktop shortcut.
